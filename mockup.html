The Basics
Swift is a type-safe language, which means the language helps you to be clear about the types of values your code can work with.

If part of your code requires a String, type safety prevents you from passing it an Int by mistake. Likewise, type safety prevents you from accidentally passing an optional String to a piece of code that requires a non-optional String.

Type safety helps you catch and fix errors as early as possible in the development process. Swift provides many standard data types, including Int for integers, Double for floating-point values, Bool for Boolean values, and String for text.
